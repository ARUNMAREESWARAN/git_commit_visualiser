# 📊 Git Commit Visualizer & Analyzer with Timeline

An interactive Streamlit dashboard that visualizes commit history from any Git repository. This tool provides insights into commit patterns, author activities, and commit timelines using beautiful charts and animations.

---

## 🚀 Features

- 📈 **Commits per Author** – Analyze which developer contributed how much.
- ⏳ **Timeline Animation** – Visualize how commit activity changed over time.
- 🧠 **Streamlit Dashboard** – Simple and interactive UI.
- 📁 **CSV-Based** – Works with `commit_data.csv` generated from your repo.

## 🧪 How to Run This Project

### ✅ 1. Clone the Repository

```bash
git clone https://github.com/DHARSHINIGANAPATHI76/git_commit_visualiser.git
cd git_commit_visualiser
````

### ✅ 2. Create Virtual Environment (Optional but Recommended)

```bash
python -m venv venv
venv\Scripts\activate     # On Windows
```

### ✅ 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### ✅ 4. Run the Streamlit App

```bash
streamlit run dashboard.py
```
